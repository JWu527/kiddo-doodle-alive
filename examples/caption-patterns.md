# 字幕句式示例（脱敏）

不要在本文件放入真实照片。

| 主题 | 推荐字幕 |
|------|----------|
| 彩虹 | `{Name}'s little rainbow :)` |
| 粉点小猫 | `{Name}'s pink dots kitty ♡` |
| 方形圆形爱心星星 | `{Name}'s little shapes ♡` |
| 通用 | `{Name}'s little doodle` |
| 未命名 | `little wonder` / `my little world`（仅当用户同意不写名字） |


## 专属署名（默认）

先问昵称，再用 `{nickname}'s {主题}`：

- `Lulu's Rainbow`
- `Lulu's Kitty`
- `Lulu's Shapes`

主题用一两个英文词，概括画面主体；没有昵称时先问，不要自编名字。
