# Kiddo Doodle Alive

Turn a child's doodle photo into a cream-paper, centered, naively lined remake, then optionally a short "comes alive" clip.

Agent Skills compatible. Not affiliated with any commercial photo/animation app.

## Install

```bash
npx skills add https://github.com/JWu527/kiddo-doodle-alive --skill kiddo-doodle-alive
```
